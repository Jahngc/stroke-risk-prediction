## Datos

El proyecto usa el [Stroke Prediction Dataset](https://www.kaggle.com/datasets/fedesoriano/stroke-prediction-dataset) de Kaggle. Los datos no se incluyen en este repositorio.

Para reproducir el proyecto:

1. Descarga el dataset desde el enlace anterior.
2. Guarda el archivo `healthcare-dataset-stroke-data.csv` en la carpeta `data/raw/`.
